# Built by Kristian

My personal portfolio site — resume, projects, and a bit about me.

Live at [builtbykristian.netlify.app](https://builtbykristian.netlify.app)

## About

A minimal, dark-themed portfolio with a blue accent. Built to be simple to update.

## Pages

- **Home** — intro, quick project highlights, contact form
- **About** — background, tech stack, interests, certifications
- **Projects** — full project list, including The Mist Project (Mist.AI Web + Desktop)
- **Resume** — embedded resume with a PDF download

## Built With

- HTML, CSS, JavaScript
- Bulma (layout/nav)
- EmailJS (contact form)
- Hosted on Netlify
